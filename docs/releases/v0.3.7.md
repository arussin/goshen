# Goshen Terminal 0.3.7

- Fix re-enabling Follow after removing cross-site access, including when Chrome grants access before the popup command finishes.
- Wait for startup permission cleanup before showing page status.
- Fix Chrome script arguments that could prevent page controls from responding.
- Label text size for ChatGPT and explain that results on other websites vary.
- Simplify the README and clarify recovery after an unpacked extension update.

Includes the 0.3.6 privacy changes: no prompt/conversation text inspection, optional cross-site following, and explicit removal of optional website access.
